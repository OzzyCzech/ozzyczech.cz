Veřejná API a generátory testovacích dat pro vývoj a testování — hodí se na prototypy, ukázky a naplnění UI daty, než je hotový backend.

## Testovací data

- **[Random User API](https://randomuser.me/api/)** — generátor náhodných uživatelských profilů včetně jmen, adres a avatarů; parametrizovatelný přes query string
- **[JSONPlaceholder](https://jsonplaceholder.typicode.com/)** — fake REST API s příspěvky, komentáři a uživateli; podporuje i `POST`/`PUT`/`DELETE` (změny se neukládají)
- **[DummyJSON](https://dummyjson.com/)** — testovací REST endpointy pro produkty, košíky, recepty a uživatele; umí stránkování i simulaci chyb

## Katalogy veřejných API

- **[public-apis](https://publicapis.dev/)** — kategorizovaný seznam veřejných API s informací o autentizaci, HTTPS a CORS
